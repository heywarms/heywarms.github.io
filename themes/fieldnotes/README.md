# Fieldnotes / Mihotel

为这个博客制作的个人主题：暖白纸面、钴蓝强调色和一个可以探索的 3D 个人储物柜。使用现有 Hexo + EJS；Three.js 随主题本地分发，无需额外后端或前端构建步骤。

## 使用

博客根目录 `_config.yml` 的 `theme` 设置为 `fieldnotes`，然后按原流程生成或发布。要恢复原主题，把该值改回 `next`。

主题只读取文章内容，不改文章、Front Matter、链接规则或 Hexo Pro 的 ID 索引。

## 定制

修改本目录的 `_config.yml`：

- `brand`、`tagline`：站点标识与一句话介绍。
- `hero`：首页标题、介绍和手写注释。
- `featured`：按现有文章标题选择首页的三篇精选。也支持 `source: _posts/xxx.md` 精确匹配。文章改名后相应更新此处。
- `about`：个人介绍和兴趣标签，现有关于页正文也会显示。
- `social.github`：GitHub 链接。
- `life.categories`：哪些现有分类的文章归入“生活切片”。
- `life.photos`：照片路径、替代文本和说明。未添加照片时显示主题原创插画，页面会标明为插画。

照片示例：

```yaml
life:
  categories: [生活, 随笔, 旅行, 摄影, 日常]
  photos:
    - src: /images/weekend.jpg
      alt: 周末傍晚的山路
      caption: 周末，慢一点
```

图片放在博客的 `source/images/` 下。相册配置无需增加 Front Matter 字段。

## 已包含

首页精选与最近文章、归档分页、分类与标签、文章阅读目录与进度、代码复制、图片放大、纯静态全文搜索、深浅色切换、手机导航、键盘操作、减少动态效果与打印样式。

静态搜索只收录已发布文章；搜索索引会与站点一同生成，无后端、无第三方搜索请求。`⌘K` / `Ctrl K` 打开搜索，`Esc` 关闭。

## 本地预览

在博客根目录运行：

```sh
node themes/fieldnotes/tools/preview.cjs --port 8796
```

打开终端给出的本地网址。这个脚本使用临时缓存目录和真实文章，跳过管理与部署插件，避免预览过程改动已有缓存和文章 ID。更改模板后重新运行预览；CSS 和浏览器脚本刷新即可生效。

只构建检查：

```sh
node themes/fieldnotes/tools/preview.cjs --build-only
```

也可用 `--root /blog/` 检查子路径部署。生产发布仍使用项目原有的 `hexo generate` / 部署流程。发布前确认博客根配置的 `url` 是你实际使用的公开域名。

## 3D 储物柜

首页与关于页包含同一组真实三维模型：

- **01 文章柜门**：点击打开，取出三本精选笔记，再打开对应文章。精选内容来自 `featured`。
- **02 生活柜门**：打开后取出山海明信片，进入生活切片。
- **03 档案抽屉**：拉开抽屉，取出并打开档案袋。关于页默认展示个人档案。
- 横向拖动旋转柜子；鼠标纵向拖动也可微调俯仰；点击“归位”收起并恢复视角。
- 触屏保留纵向页面滚动。所有开合、取出和内容入口也有普通按钮，可用键盘操作。
- 聚焦模型后，方向键改变视角，`1` / `2` / `3` 打开格子，`Esc` / `Home` 归位。

模型使用真实几何体、铰链、光照、阴影与点击拾取。仅在交互、视口变化时绘制；离开屏幕或切到后台暂停。尊重系统的“减少动态效果”。无法使用 WebGL 时显示预览图和普通内容链接。文章阅读页不加载 3D 资源。

本地依赖为 Three.js 0.180.0，许可证与来源在 `source/vendor/three/`。模型和交互代码位于 `source/js/locker.js`，样式在 `source/css/locker.css`。
