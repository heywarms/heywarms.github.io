# Fieldnotes / Mihotel

为这个博客制作的个人主题：暖白纸面、钴蓝强调色和一个可以探索的 3D 个人储物柜。使用现有 Hexo + EJS；Three.js 随主题本地分发，无需额外后端或前端构建步骤。

这是个人自用的品牌站主题，不作为开源主题或公共主题商品发布。设计和配置围绕站点主人的内容与审美维护，不以适配其他用户为目标。Hexo Pro 中的入口来自本地已安装主题识别，不代表加入公共主题目录。

主题包保留 `private: true` 并标记 `UNLICENSED`；第三方依赖的原有许可证与署名保留在各自目录。`private` 只阻止 npm 发布，不控制 GitHub 仓库可见性。

## 使用

博客根目录 `_config.yml` 的 `theme` 设置为 `fieldnotes`，然后按原流程生成或发布。要恢复原主题，把该值改回 `next`。

主题只读取文章内容，不改文章、Front Matter、链接规则或 Hexo Pro 的 ID 索引。

## 定制

推荐在 **Hexo Pro → 主题 → Fieldnotes → 配置 → 表单模式** 中调整，保存后刷新博客即可。表单支持中文名称、颜色选择、开关、下拉选择，以及列表的添加、删除和上下排序；保存前会保留配置快照。

也可以直接编辑博客根目录的 **`_config.fieldnotes.yml`**。本目录 `_config.yml` 是默认配置；自定义值放在博客根目录，更新主题时更容易保留。优先级为：站点 `_config.yml` 中的 `theme_config` → 根目录 `_config.fieldnotes.yml` → 主题默认值。数组按你的配置整体替换，`[]` 表示清空，`false` 表示关闭。

常用配置：

- `navigation`：导航的标题、链接、新窗口开关及显示顺序。
- `appearance`：默认深浅模式、是否允许访客切换、两种模式的强调色和背景色、内容宽度、正文字体。颜色使用六位十六进制。关闭切换按钮时固定使用配置模式；允许切换时访客的偏好优先。
- `home.order`：首页模块顺序，可选 `hero`（开场）、`interlude`（兴趣横栏）、`topics`（专题）、`featured`（精选）、`projects`（作品）、`journal`（最近文章）、`about`（个人介绍），以及电影感模块 `stage`、`episode`、`notes`、`profile`、`dispatch`（见下文“电影感首页”）。省略模块或设置对应 `enabled: false` 即可隐藏；专题和作品没有内容时自动隐藏。模块序号自动跟随显示顺序。
- `home` 下的各模块：文案、入口文字、精选/最近文章数量、生活侧栏开关。隐藏首页入口不会删除独立页面。
- `locker`：3D 开关、关于页开关、柜体与柜门颜色、柜顶文字、明信片和静态封面。关闭 3D 后显示静态图片，不加载 Three.js；默认保留原来的 3D 交互。
- `features`：搜索、代码复制和图片放大开关。关闭搜索同时停止生成搜索索引。
- `article`：桌面目录、手机目录、进度条、阅读时长、文章信息、分享、标签和专题连续阅读开关，互相独立。
- `article.style`：站内页面的阅读风格。`paper`（默认）是原来的纸张版式，跟随深浅色；`voyage` 是星舰阅读：深空背景上缓缓漂移的三层星辰（滚动时有视差，偶尔划过流星）、窗外远处一颗星球的亮边，页头是悬浮的玻璃胶囊。文章正文放在带角标的玻璃阅读面板里，代码块像飞船终端，目录变成带节点的航线。同一片星空也铺到归档、分类、标签、专题、关于、生活、作品和普通页面，列表保留各自的版式，换成深色玻璃卡片和发光的悬停效果，离开文章时不会跳回纸张；首页保持自己的设计。星空用 Canvas 绘制，约 30 帧、切到后台时暂停，系统开启「减少动态效果」时静止；打印时自动换回白底黑字。这一风格只有一种配色，所以这些页面不显示深浅色切换按钮。共享的星空、配色和组件在 `voyage-space.css`，只属于文章页的部分在 `voyage-reader.css`。
- `topic_hero`：专题页开场。每个专题是一颗在浏览器里实时绘制的星球：地表（大陆与海洋、气态条带与风暴、陨石坑与峡谷）先用多层噪声在显卡上烘焙一次，再按真实光照渲染，有昼夜分界、水面反光、会投下影子的流动云层、边缘的大气辉光，气态巨行星的光环还会和星球互相投影。当前专题的星球铺满下方天空，另外两颗半露在屏幕左右边缘，点击即互换，标题、介绍和按钮跟着换。不需要任何外部素材；系统开启「减少动态效果」时星球静止、切换不带动画；离开屏幕时停止渲染。专题可写 `planet` 指定类型（`ocean`、`gas`、`desert`、`ice`、`lava`）。
- `list_backdrop`：文章列表（归档、分类、标签、首页第 2 页起）的开场背景。一段缓慢循环的视频铺满首屏，标题、说明和筛选按钮居中压在画面最亮处，一层专门调过的遮罩保证文字看得清，手机上遮罩更重。视频底部渐隐到页面背景，往下滚逐渐变暗，文章列表始终在深色背景上。`poster` 是视频首帧，加载前先显示，避免闪白；`hue` 可以整体偏色，让素材靠近站点配色。视频离开屏幕时暂停，系统开启「减少动态效果」时停在第一帧。
- `about.hero`：关于页首屏。开启后关于页以一段全屏循环视频开场：视频结束前 0.55 秒淡到黑、再从头淡入，看不出循环；上面是液态玻璃的页头、大号衬线标题（Instrument Serif，`*单词*` 显示为斜体）、一条玻璃输入条、副标题和「了解更多」按钮，底部是社交图标。储物柜不再显示。首页 `connect.form_action` 填了订阅地址，玻璃条就是真的邮箱输入框；没填时它变成跳到 `cta_url`（留空用第一个社交链接）的链接，不会放一个提交不了的表单。`shift` 把视频往下移，适合主体在画面下方的素材。视频滚出屏幕时暂停；系统开启「减少动态效果」时停在第一帧。
- `footer`：页脚文字、自定义链接、起始年份和 Hexo 链接开关。

- `brand`、`tagline`：站点标识与一句话介绍。
- `hero`：首页标题、介绍和手写注释。
- `featured`：按现有文章标题选择首页的三篇精选。也支持 `source: _posts/xxx.md` 精确匹配。文章改名后相应更新此处。
- `topics`：专题标题、介绍与阅读顺序。`sources` 按文章在 `source/` 下的相对路径排序；`categories` 中的新文章会自动追加。缺失、草稿和未发布文章不会出现在路线中，空专题不展示。专题页自动生成于 `/topics/`，无须新增 Markdown 页面。
- `projects`：作品介绍、真实截图、技术标签、功能说明和项目链接。自动生成 `/projects/`；第一项也会出现在首页与关于页。
- `about`：个人介绍和兴趣标签，现有关于页正文也会显示。
- `social`：GitHub、B站、小红书、抖音、公众号、RSS 和邮箱。填写后会出现在电影感首页的开场和订阅区，留空的平台不显示。
- `brand_avatar`：导航栏头像图片，填写后替代星形标志，全站生效。
- `life.categories`：哪些现有分类的文章归入“生活切片”。
- `life.photos`：照片路径、替代文本和说明。未添加照片时显示主题原创插画，页面会标明为插画。
- `article.notice`：文章底部的引用与来源提示。`article.updated_dates` 可单独记录更新日期，不需要改 Front Matter。已有 Front Matter 的 `updated` 也会被读取；只有晚于发布日期的有效日期会展示，不使用文件修改时间或 CI 克隆时间。

更新日期示例（值建议加引号）：

```yaml
article:
  updated_dates:
    _posts/Docker快速入门.md: '2026-10-15'
```

照片示例：

```yaml
life:
  categories: [生活, 随笔, 旅行, 摄影, 日常]
  photos:
    - src: /images/weekend.jpg
      alt: 周末傍晚的山路
      caption: 周末，慢一点
```

图片放在博客的 `source/images/` 下。相册配置无需增加 Front Matter 字段。

## 电影感首页

把 `home.order` 设为 `[stage, episode, notes, profile, dispatch]` 即换成以视频和 IP 形象为主的深色首页；改回经典模块即可恢复原首页。电影感模块只在首页第一页加载自己的样式和脚本（`css/cinema.css`、`js/cinema.js`），文章页、归档页仍使用原来的阅读样式。

- 玻璃卡片版首页：`home.order` 设为 `[stage, routes, glossary, videos, updates, connect]`，首屏之下是一组玻璃卡片，比整屏楼层更像博客：
  - `routes`：学习路线卡片（最多 3 条）。`topic` 关联已有专题（显示篇数，并链接到第一篇），`planned` 列出规划中的选题，`region` 是星球短名，`planet` 是星球样式。
  - `glossary`：大白话词典，每项 `term` / `en` / `definition`，可加 `url` 链接到详细笔记。
  - `videos`：视频 × 笔记。`post` 为配套文章，`poster` 可填 B站封面，留空显示抽象光效；`extras` 是“这一期的配套”，`more` 是往期小卡片。
  - `updates`：最近更新列表，`archive.categories` 中分类的文章合并为一行“早期档案”；`upcoming` 为预告。
  - `connect`：关于我与订阅。IP 动画放在这里的 `video` / `poster`；`show_project` 显示第一个作品；`form_action` 填订阅服务地址后出现邮箱输入框。
- `archive`：早期档案。`categories` 中分类的文章不上首页列表，合并为一行，并作为首屏最后一颗星球（样式由 `planet` 决定）。
- `stage`：首页开场。`visual: planets` 是一段星际旅行：开场是上帝视角的星图，每条学习路线各是一个旋涡星系（双臂、棒旋、多臂絮状等，带尘埃带和粉色的恒星形成区），早期档案是一个没有旋臂的老年椭圆星系，背后有星云和银河带。星系有远有近、各自朝向不同并缓慢旋转，镜头会轻轻漂移、跟着鼠标偏转，近处的星系和散落的星星移动得更快，看起来更有纵深。星图上标着飞船的「当前位置」（一开始在基地，去过哪个星系就停在哪个星系旁边）。点星系名或下方按钮锁定目的地时，会像星际航图一样画出一条从当前位置到目的地的弧形航线，光点沿航线流向目标，并标出航程；镜头会在一组候选机位里挑出最能看清这条航线、又不让星系和标签出画的角度，平滑转过去。「启动跃迁」是一个点火按钮：涡轮加速、尾焰喷出、倒数 3·2·1，然后合上驾驶舱，以第一视角俯冲到飞船位置，沿着画好的航线加速飞行（转弯时机身倾斜，途中从其他星系旁掠过），星光拉成光束、穿过闪光，减速进入这个星系的星球轨道。驾驶舱有座舱框、仪表台和 HUD（速度、距离、航向、当前阶段）。抵达后显示路线卡片和「返回星图」。抵达后点其他按钮会直接跃迁到下一颗星球。星球各有地貌和卫星：海洋星球（云层、卫星、数据环）、气态巨行星（深浅不一的云带、大风暴和一串白色小风暴、土星式多层光环）、暖阳星球（`desert`：青绿的海、绿谷和金色草原、琥珀色秋林、河流和云层，夜面亮起城镇灯光，带空间站和人造卫星）、冰封星球（陨石坑、小行星带）、熔岩星球（发光裂谷）。星图和星球都可以拖动旋转；星系和地貌全部在浏览器里程序生成，使用主题自带的 Three.js，不加载额外资源。系统开启「减少动态效果」时跳过飞行直接切换，没有 WebGL 时显示一颗光球和同样的切换按钮。`visual: sphere`（默认）在右侧显示可随鼠标转动的 3D 粒子球，`chips` 是周围漂浮的标签（最多 5 个）；`visual: video` 改为全屏背景视频，使用 `video` / `video_webm` / `poster`（电脑横版）和 `mobile_*`（手机竖版，可留空）。`heading` 每项一行，`signature` 是叠在标题上的手写签名。导航栏在这一屏变成悬浮的玻璃胶囊。
- `episode`：最新一期。`post` 填配套文章（`_posts/文件名.md` 或标题），`video_url` 填 B站等观看地址；没有观看地址时封面链接到文章。封面可以用视频或 `poster` 图片（例如 B站封面），都留空时显示抽象光效封面。`cards` 最多 3 张小卡片。
- `notes`：杂志式文章列表。`exclude_categories` 中分类的文章不在首页出现，合并为一行“早期档案 · N 篇”；`upcoming` 为预告条目。
- `profile`：米白底的关于我，`description` 留空时沿用 `about.description`；`facts` 为“标签 / 内容”，`stickers` 为贴纸文字。
- `dispatch`：订阅区与底部大字标。填写邮件订阅服务的 https 表单地址到 `form_action` 后才出现邮箱输入框，否则只显示社交链接。
- `cinema`：`accent` 是签名与重点颜色；`sphere_a` / `sphere_b` 是粒子球和抽象封面的两种颜色；`fonts` 是 Anton + Condiment 字体样式表。国内访问 Google Fonts 不稳定时，会回落到 Impact 等系统字体；也可以把字体放进主题后改成自己的地址，留空则只用系统字体。

视频文件放在博客 `source/videos/` 下，按 `/videos/xxx.mp4` 引用。视频始终静音，粒子球和视频都由脚本在进入视口时播放、离开时暂停；访客开启“减少动态效果”或点击首屏右下角的暂停按钮后，粒子球停在静止画面、视频只显示封面图。没有 JavaScript 时同样显示静止画面。

## 已包含

首页精选与最近文章、专题阅读路线、作品展示、归档分页、分类与标签、文章阅读目录与进度、同专题上下篇、更新与来源信息、代码复制、图片放大、纯静态全文搜索、深浅色切换、手机导航、键盘操作、减少动态效果与打印样式。

手机文章页使用可展开的悬浮目录，选择章节后自动收起，也支持 Esc 关闭。桌面保留侧栏目录；文章无标题时不展示空目录。文章仍可在 JavaScript 不可用时阅读和跳转章节。

静态搜索只收录已发布文章；搜索索引会与站点一同生成，无后端、无第三方搜索请求。`⌘K` / `Ctrl K` 打开搜索，`Esc` 关闭。

## 本地预览

在博客根目录运行：

```sh
node themes/fieldnotes/tools/preview.cjs --port 8796
```

打开终端给出的本地网址。这个脚本使用临时缓存目录和真实文章，跳过管理与部署插件，避免预览过程改动已有缓存和文章 ID。更改模板或配置后重新运行预览；CSS 和浏览器脚本刷新即可生效。预览会读取博客根目录的 `_config.fieldnotes.yml`。

只构建检查：

```sh
node themes/fieldnotes/tools/preview.cjs --build-only
```

也可用 `--root /blog/` 检查子路径部署。生产发布仍使用项目原有的 `hexo generate` / 部署流程。发布前确认博客根配置的 `url` 是你实际使用的公开域名。

## 3D 储物柜

首页与关于页包含同一组真实三维模型：

- **01 文章柜门**：点击打开，取出笔记。配置了非空 `topics` 时，三本笔记对应前三个专题，取出后打开有顺序的阅读路线；未配置专题时回退到 `featured` 精选文章。
- **02 生活柜门**：打开后取出山海明信片，进入生活切片。
- **03 档案抽屉**：拉开抽屉，取出并打开档案袋。关于页默认展示个人档案。
- 横向拖动旋转柜子；鼠标纵向拖动也可微调俯仰；点击“归位”收起并恢复视角。
- 触屏保留纵向页面滚动。所有开合、取出和内容入口也有普通按钮，可用键盘操作。
- 聚焦模型后，方向键改变视角，`1` / `2` / `3` 打开格子，`Esc` / `Home` 归位。

模型使用真实几何体、铰链、光照、阴影与点击拾取。仅在交互、视口变化时绘制；离开屏幕或切到后台暂停。尊重系统的“减少动态效果”。无法使用 WebGL 时显示预览图和普通内容链接。文章阅读页不加载 3D 资源。

本地依赖为 Three.js 0.180.0，许可证与来源在 `source/vendor/three/`。模型和交互代码位于 `source/js/locker.js`，样式在 `source/css/locker.css`。

## 验证

阅读排序、草稿过滤、重复配置与更新日期逻辑可用 `node --test themes/fieldnotes/tools/content.test.cjs` 检查。新增页面使用现有主题资源，不增加远端服务。项目截图来自 Hexo Pro 仓库的 `hexo-pro/docs/editor-page.png`；后续可替换 `projects[].image` 为新版截图。

## 配置示例

只保留开场、最近文章和个人介绍，并改成绿色：

```yaml
appearance:
  accent: '#17745c'
  accent_dark: '#8ed8bd'
home:
  order: [hero, journal, about]
  journal:
    limit: 6
    show_life: false
locker:
  articles_color: '#17745c'
```

关闭 3D 只需 `locker.enabled: false`；静态封面可通过 `locker.poster` 换成自己的图片。以上只修改主题配置，不需要碰文章 Front Matter。

用临时配置验证不同风格，不覆盖正式配置：

```sh
node themes/fieldnotes/tools/preview.cjs --port 8797 --theme-config /path/to/alternate.yml
```

配置默认值、开关、数组替换、安全链接与电影感首页检查：

```sh
node --test themes/fieldnotes/tools/content.test.cjs themes/fieldnotes/tools/settings.test.cjs themes/fieldnotes/tools/cinema.test.cjs
```

`_config.schema.json` 随主题提供中文表单定义；Hexo Pro 也可读取博客根目录 `_config.fieldnotes.schema.json` 作为自定义表单覆盖。需要通过 GitHub Actions 构建时，主题源码和个人配置应存放在私有源码仓库，由原来的构建流程将生成的网站部署到 EdgeOne。向公开源码仓库同步主题之前，需要重新确认站点主人的意愿。
