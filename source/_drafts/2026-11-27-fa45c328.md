# 网络

这个不用多说，网络是一切的前提，必备科学干净网络，防止被谷歌风控。可以通过ip检测来检查一下自己ip的纯净度。

# 账号

第一个要解决的就是账号问题，要使用谷歌的antigravity的前提有两个，分别是账号和ip，谷歌不像openai，只需要满足ip就行，它对用户有严格的账号区域限制。如果你已经有谷歌账号可以打开polices.google.com查看自己的账号区域。这一步一定要做，因为我遇到很多人充了钱订阅了最后发现无法使用，结果发现是账号区域不对。如果发现账号区域不对你可以有一次改区机会，进入下面的网址进行改区，提交申请时确保你的网络区域是对应区域的干净网络，选择留学和工作原因提交，一般3个小时内就能审批通过。

如果改区失败，可以重新注册账号，但是注册前请务必使你访问谷歌为对应区域的干净网络。只有这样注册完你的账号才会在对应区域。如果你注册时发现要求扫码验证或者需要你发送短信，大概率短信发送失败，这时就是被风控了。两种原因一个是你的网络不干净，一个是你这台电脑注册过太多账号了。如果遇到这种情况，请确保网络干净的前提下，使用手机，下载GoogleAPP，使用APP进行注册，可以绕过扫码校验。

# 订阅

# 反重力登录校验

订阅完成了反重力登陆后可能会要求校验你的账号，如果你直接点击校验，多半又会触发风控，让你扫码发短信，然后短信又发送失败，进入死循环。这个时候我们需要进入谷歌云，点击右上角的终端，终端加载后也会让你校验账号，我们在这里点击校验账号，风控就会出现降级后的接收验证码选项，我们在这里选择接收验证码，校验通过后我们再登录antgravity就能发现正常登录了。

# 还有一关

这时你登录上了反重力可能还是访问不了模型，会报错，这是因为桌面端的反重力进程会绕过你的本地代理，所以请务必开启TUN模式。
